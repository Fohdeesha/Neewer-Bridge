================================================================================
DMX CHANNEL TABLE — MODE 1: CCT MODE
================================================================================

Channel  | Function          | DMX Value | %          | Setting
---------|-------------------|-----------|------------|------------------
n        | Mode Selection    | 0-31      | (0%-12%)   | CCT Mode
n+1      | Brightness        | 0-255     | 0-100      | 0-100%
n+2      | Color Temperature | 0-255     | 0-100      | 2500-10000K
n+3      | G/M               | 0-255     | 0-100      | -50-0-50
